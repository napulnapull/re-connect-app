01 · OVERVIEW

프로젝트 개요

초보 개발자가 구현 가능한 범위에서 시작하되, 커뮤니티의 신뢰·지속성·확장성을 처음부터 고려한다.

🎯

목표

돌싱 회원이 부담 없이 정보를 읽고, 안전하게 관계를 만들며, 온라인 활동이 실제 취미·지역 모임으로 이어지는 플랫폼 구축.

🧭

서비스 방향

소개팅 앱이 아니라 ‘라이프 커뮤니티’. 외모 경쟁보다 관심사·활동 지역·커뮤니티 기여도를 중심으로 연결.

🛠️

개발 원칙

모바일 우선, 기능 단위 구현, 화면 ID 관리, 더미 데이터로 먼저 검증, 이후 인증·DB·실시간 기능을 단계 적용.

ONE SENTENCE“가입을 강요하기보다 먼저 분위기를 보여주고, 신뢰가 필요한 행동에만 단계적으로 인증을 요청한다.”

03 · VALUE

핵심 가치와 제품 원칙

서비스의 모든 화면과 기능은 아래 네 가지 기준으로 판단한다.

🌱

✨

하지 않을 것

무한 외모 스와이프, 자극적인 인기 순위, 강제 개인정보 공개, 운영자가 추적할 수 없는 완전 무기명 구조.
